# 设计阶段留档：用 OpenDesign 迭代展示页

这份目录记录 v1.2「本地只读展示页」的**设计阶段过程** —— 输入是什么、交给了什么工具、
工具产出了什么、产出又是怎么变成仓库里那份代码的。

规范层的记录在 `specs/adrs/004-展示层技术选型.md`，和这份目录对照着看就是完整链条。

## 目录里有什么

| 路径 | 是什么 |
|---|---|
| `brief/` | **输入**。交给 OpenDesign 之前准备的 6 份材料，原样存档 |
| `mock/opendesign-output.html` | **产出**。OpenDesign 给的设计原型，851 行、自包含、未改动 |
| `screenshots/` | **落地后**的真实页面截图（`python main.py --serve` 跑出来截的，不是设计效果图） |

## 用的工具与设计系统

- **工具**：OpenDesign（本地安装版）
- **设计系统**：`ant`（`design-tokens.json`，格式 `od-design-tokens/v1`，56 个 token，自评 100 分）

设计稿里的 `:root` 令牌块**逐字搬进了** `webview/static/app.css`。这一点是实测过的，
不是"差不多"：

```bash
# 设计稿 :root 与 app.css :root 对比：36 个 token，名字与取值全部一致
#   名字相同的 token：36 个一致 / 0 个不一致
#   设计稿独有：无       app.css 独有：无
```

理由很直接：颜色、字号、间距、圆角一律**不自己发挥**。凭感觉调色是设计稿失真最常见的来源。

## 设计稿实测（怎么核）

设计稿是**自包含**的 —— 双击 `mock/opendesign-output.html` 就能看，不需要任何外部资源：

```bash
# 全文没有一处外部依赖（CDN / 远程脚本 / 远程样式表）
grep -c -E 'https?://|cdn\.|<script[^>]*src=|<link[^>]*href=' design/mock/opendesign-output.html
# → 0
```

结构（按文件内的分块注释）：

| 行号 | 区块 |
|---|---|
| `:243` | 列表页 |
| `:314` | 详情页 |
| `:511` | 异常与空态 —— 三种特殊状态（数据源失败 / 考勤不可用 / 今日无记录） |
| `:703` | 设计规范 —— 色板、字号阶梯、间距、圆角、组件示例 |

## 从设计稿到代码：改了什么

这是整份文档最该看的一页 —— **设计稿没被照抄，而是逐项判过**：

| 设计稿里 | 落地成 | 为什么 |
|---|---|---|
| 36 个 design token（`:root`） | `app.css` 的 `:root`，**逐字照搬**（实测名字+取值全一致） | 设计系统是权威 |
| 字体族 `--font` / `--mono` | **与设计稿完全一致**（`app.css:43-44`） | `ant` 的设计系统文档里写的是 `Ant Sans` / `Alibaba PuHuiTi`，本机未安装；设计稿本身已经用了系统字体栈兜底，落地沿用 |
| 6 处 `font-size:13px` | `--fs-12`（12px） | 13px 不在 `ant` 的字号阶（12/14/16/18/22/32）上，属设计稿笔误 |
| `.review-nav`（`mock:811`，自带 `aria-label="设计稿导航（评审用，非产品界面）"`） | **不落地** | 设计稿自己标注了"评审用、非产品界面"，不是产品功能 |
| 设计规范展示块（`:703`）、独立的状态示例块 | **不落地** | 同上，是给评审看的说明，不是界面 |
| 组件里的静态示例数据 | `fetch('/api/reports')` 取真实数据 | 数据必须来自真实 SQLite，不能内联假数据 |

每一条的取舍理由也追加记在 `specs/adrs/004-展示层技术选型.md` 的「补充记录」里
（ADR 只追加、不修改，这是规范层的规矩）。

## 落地后没有丢掉硬约束

设计稿再好看，也不能突破 `specs/design.md` §6.5 的三条（由 `scripts/input_guard.py` 规则 4 强制，
违反会被护栏拦下）：

1. **只读** —— SQLite 以 `mode=ro` 打开，写操作在连接层就失败；HTTP 写方法一律 405
2. **只绑定回环地址** —— 传 `0.0.0.0` 直接拒绝启动（退出码 2）
3. **运行时零新增依赖** —— 只用 Python 标准库 + 原生 HTML/CSS/JS，无框架、无构建步骤

第 3 条尤其值得说明：设计稿本身也是零外部依赖的，所以**落地时没有任何外部资源被带进仓库** ——
这不是限制，是设计稿和硬约束恰好对齐。

**保留原样、不做修订**，在此说明：
