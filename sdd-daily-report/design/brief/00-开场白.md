# 简短版开场白（如果它不支持附件，用这个，但会损失细节）

> 帮我设计一个「团队工作日报」的本地浏览页，纯 HTML + CSS + 原生 JS，全中文，不要 React 不要构建步骤。
>
> **页面就一条主线**：左边/上面是按日期倒序的日报列表 → 点进去看详情。
>
> **列表项**显示：日期、团队名、生成时间、成员名字、数据健康度（全部正常 / 有缺失 / 全部失败）。
>
> **详情页**依次是：抬头（日期+团队名+生成时间）→ 总览表（成员 / 代码提交数 / 任务进展数 / 协作沟通数）→ 每个成员一张卡片，卡片里四段：**代码提交**（仓库名、commit message、+增/-删 用绿红区分、改动文件数）、**任务进展**（标题、`进行中 → 已完成` 状态流转）、**考勤**（工时如 9.5h、状态正常/迟到用语义色、签到签退时刻）、**协作沟通**（群名 + 消息内容，做成引用样式）。
>
> **必须设计出这三个特殊状态**：① 某数据源失败 → 显式显示「数据获取失败」；② 缺考勤 → 显示「考勤数据暂不可用」；③ 当天无记录 → 显示「今日无记录」。
>
> 样例内容长这样：
> ```
> # 平台研发组工作日报 — 2026-08-20
> ## 总览
> | 成员 | 代码提交 | 任务进展 | 协作沟通 |
> | 张三 | 2 | 1 | 1 |
> ## 张三
> ### 代码提交
> - `example-org/example-repo` feat: 日报三段式编排 （+120/-18，4 个文件）
> ### 考勤
> - 工时 9.5h，状态：正常 （09:32 - 19:05）
> ```
>
> **不要做**：登录、权限、编辑日报、数据源配置页、统计图表、暗色模式切换、移动端适配。
>
> 交付：高保真原型（HTML/CSS/JS）+ 设计系统（配色 hex、字号阶梯、间距、语义色）+ 组件清单 + 三种特殊状态的视觉 + 截图。
